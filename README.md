# Niva Kalia - Personal Profile

A simple, elegant personal profile webpage using HTML and CSS.

## Files
- index.html
- style.css
- profile.svg

## Design
Pastel green and cream palette with bordered boxes, rounded corners, simple typography,
skills tags, and a basic responsive layout.

## GitHub Pages
1. Create a public repository named `nivakalia.github.io`.
2. Upload the files to the root.
3. Go to Settings -> Pages.
4. Select Deploy from a branch.
5. Select `main` and `/ (root)`.
6. Click Save.

Replace `profile.svg` with your actual profile photograph before submission.
